# Superseded figure scripts

These three scripts generated the figures up to revision v5. They are retained only for
provenance and are no longer invoked by `run_all.py`.

All figure rendering is now done by `../make_figures.py`, which applies a single
typographic system across every panel. The numerical modules these scripts imported
(`multispin_chain.py`, `transport_floquet.py`, `target_spin_gap.py`) are unchanged and live
in the parent directory.
