# Deterministic numerical results

This directory contains the machine-readable outputs of the model calculations used for the figures and numerical statements in the manuscript and Supplementary Material.

Key provenance:

- `floquet_ep_scan.csv` — dissipative-modulation exceptional-point scan; generated by `code/run_ep_scan.py`.
- `floquet_convergence.csv` and `floquet_convergence_fit.json` — time-discretization convergence and extrapolation; generated by `code/run_convergence.py`.
- `transport_sensitivity.csv` — tip-polarization and tip-angle robustness scan; generated by `code/run_transport_sensitivity.py`.
- `metrology_scan.csv` — coherent-drive information scan; generated by `code/run_metrology_extended.py`.
- `target_gap_scan.csv` and `target_gap_fit.json` — target-spin gap calculation; generated by `code/run_target_gap.py`.
- `one_port_checks.json` — numerical checks of participation, residue, rigidity, and sum-rule identities.
- `one_port_rigidity_scan.csv` — one-port phase-rigidity scan.
- `one_port_slow_mode.csv` — slow-mode participation, residue, and rigidity scaling.
- `one_port_spectrum.csv` and `one_port_spectrum_modes.csv` — one-port susceptibility and modal decomposition.
- `multispin_scaling.csv`, `multispin_length_scales.csv`, and `multispin_validation.csv` — network scaling, design scales, and full-Liouvillian validation outputs.

The one-port tables are generated by `code/run_one_port_response.py`; figure rendering is performed by `code/make_figures.py`.

To regenerate all model outputs from the repository root:

```bash
python run_all.py \
  --data-root /path/to/Data_Repository \
  --recompute-transport
```
